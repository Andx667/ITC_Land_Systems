# GTK Boxer Compatibility

`itc_land_compat_gtk_boxer`: Loads only with GTK Boxer. ITC versions of the Boxer RCH 155 (ammunition handler, mounted tablet, ITC sight readouts, ITC 155 mm L/52 rounds like the Sholef 2).

## Dependencies

- ITC: `itc_land_common`, `itc_land_ballistics`, `itc_land_veh_sights`, `itc_land_veh_weapons`, `itc_land_sphammohandler`
- ACE: `ace_interaction`
- Other mods: `Hawks_GTK_Boxer`

- `CfgVehicles.hpp`
