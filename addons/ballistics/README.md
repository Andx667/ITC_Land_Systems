# Ballistics

`itc_land_ballistics`: Ballistic tables, firing solutions and the [BCS battery types](../../docs/scripting.md#battery-types).

## Dependencies

- ITC: `itc_land_common`
- ACE: `ace_common`, `ace_mk6mortar`

## Files

- `CfgMisc.hpp`

## Functions

| Function | Public | What it does |
| --- | --- | --- |
| `fnc_calcBtabSolution` |  | Computes the firing solution for one charge from its ballistic table (as generated by tables\calcBallistics.sqf) for a given horizontal distance and height difference between gun and target. |
| `fnc_calcFuzeSetting` |  | Computes the time fuze setting (FS) of a firing solution: the time after firing at which the shell, on the way down, passes its round's burst height above the target (itc_land_burstHeight, metres). |
| `fnc_calcShellTypeSolutions` |  | Computes firing solutions for every available charge of a given shell type, from a gun position/elevation/direction to a target position/elevation. |
