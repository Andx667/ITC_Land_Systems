# BWMod Compatibility

`itc_land_compat_bwa3`: Loads only with BWMod. ITC versions of the Panzerhaubitze 2000 (ammunition handler, mounted tablet, ITC sight, ITC 155 mm L/52 rounds with German designations), firing tables and a BCS battery type for the MRS120 mortar.

## Dependencies

- ITC: `itc_land_common`, `itc_land_ballistics`, `itc_land_veh_sights`, `itc_land_veh_weapons`, `itc_land_sphammohandler`
- ACE: `ace_interaction`
- Other mods: `bwa3_pzh2000`, `bwa3_mrs120`

- `CfgBallistics.hpp`
