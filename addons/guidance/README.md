# Guidance

`itc_land_guidance`: Laser and GPS guidance of the guided rounds.

## Dependencies

- ITC: `itc_land_common`

## Functions

| Function | Public | What it does |
| --- | --- | --- |
| `fnc_lgm15x` |  | Fired EH handler for a laser-guided precision munition (LGM15x). |
| `fnc_pgm15x` |  | Fired EH handler for a GPS/INS-guided precision munition (PGM15x). |
| `fnc_pgm230` |  | Fired EH handler for a longer-range GPS/INS-guided rocket (PGM230). |
