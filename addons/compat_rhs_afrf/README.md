# RHS AFRF Compatibility

`itc_land_compat_rhs_afrf`: Loads only with RHS: AFRF. ITC versions of the 2S1 Gvozdika and 2S3 Akatsiya (ammunition handler, mounted tablet, ITC sight), ITC sights for the D-30, firing tables and BCS battery types for the D-30 and the 2B14 Podnos mortar (the old ITC 2B14 stays hidden for old missions).

## Dependencies

- ITC: `itc_land_common`, `itc_land_ballistics`, `itc_land_veh_sights`, `itc_land_veh_weapons`, `itc_land_sphammohandler`
- ACE: `ace_interaction`
- Other mods: `rhs_c_2s1`, `rhs_c_2s3`, `rhs_c_heavyweapons`
