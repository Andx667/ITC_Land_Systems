# RHS USAF Compatibility

`itc_land_compat_rhs_usaf`: Loads only with RHS: USAF. ITC versions of the M109A6 Paladin (ammunition handler, mounted tablet, ITC sight), ITC sights for the M119A2, firing tables and BCS battery types for the M119A2 and the M252 mortar (the old ITC M252 stays hidden for old missions).

## Dependencies

- ITC: `itc_land_common`, `itc_land_ballistics`, `itc_land_veh_sights`, `itc_land_veh_weapons`, `itc_land_sphammohandler`
- ACE: `ace_interaction`
- Other mods: `rhsusf_c_m109`, `rhsusf_c_heavyweapons`, `rhsusf_c_statics`
