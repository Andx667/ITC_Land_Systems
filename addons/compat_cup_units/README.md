# CUP Units Compatibility

`itc_land_compat_cup_units`: Loads only with CUP Units (and CUP Weapons). ITC versions of the D-30 and M119 (ITC sight, no vanilla artillery computer), firing tables and BCS battery types for both.

## Dependencies

- ITC: `itc_land_common`, `itc_land_ballistics`, `itc_land_veh_sights`
- Other mods: `CUP_Weapons_Ammunition`, `CUP_Weapons_VehicleWeapons`, `CUP_Weapons_StaticWeapons`, `CUP_Creatures_StaticWeapons`

## Files

- `CfgBallistics.hpp`
- `CfgMagazines.hpp`
- `CfgVehicles.hpp`
