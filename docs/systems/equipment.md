# Other Equipment

## Remote frag grenade

The **Remote Frag** (`ITC_Land_remoteFrag_mag`) is a fragmentation grenade you place like an ACE explosive and set off from a distance.

1. Place it with ACE explosives: self interaction → **Explosives** → **Place** → **Remote Frag**.
2. Connect a detonator: it works with the ACE **Command** trigger (clacker) and the **MK16 Transmitter**.
3. Detonate it with the detonator like any other ACE explosive.

## Smoke dispenser

The **CM Smoke Dispenser** (`itc_land_smokeDispenser_mag`) is a vehicle magazine for a smoke countermeasure dispenser. It is not available in the Arsenal, and no ITC vehicle carries it yet; vehicle mods can add it to their own vehicles.
